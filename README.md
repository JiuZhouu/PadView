# PadView · 拍摄计时器

拍 vlog 时摆在画面里的计时看板。单个 `index.html`，无依赖、可离线。

**在线地址：<https://jiuzhouu.github.io/PadView/>** —— iPad 直接用 Safari 打开即可，推送到 `main` 会自动重新构建。

## 界面

```
┌──────────────────────────────────────────────┐
│ [开始] [重置] [全屏] [设置]  ● 计时中 · 第 1 段 │  ← 闲置 4 秒自动淡出
├──────────────────────┬───────────────────────┤
│ 开始时间             │                       │
│ 11:02:04             │  已进行时间           │
│                      │                       │
│ 当前时间             │  00:00:08             │  ← 醒目大字
│ 11:17:06             │                       │
├──────────────────────┴───────────────────────┤
│ #1 11:02:04 → 11:02:11 00:00:07  #2 …计时中   │  ← 自动生成的分段记录
└──────────────────────────────────────────────┘
```

竖屏会自动改成上下堆叠。

## 基本用法

只靠一个主按钮循环，没有需要手动打点的操作：

| 按钮 | 状态 | 说明 |
| --- | --- | --- |
| **开始** | 就绪 | 记录「开始时间」并开启第 1 段计时 |
| **暂停** | 计时中 | 结束当前段，**自动存下一条记录** |
| **重启** | 已暂停 | 接着上一段继续累计，同时开启新的一段 |
| **重置** | 任意 | 需连点两次确认，清空计时与全部记录 |
| **全屏** | 任意 | 浏览器支持时进入全屏；iPad 上更推荐「添加到主屏幕」 |

自动化行为：

- **自动记录每一段**：每次暂停都会生成一条 `段号 / 开始时刻 / 结束时刻 / 时长`，正在计时的那段会实时跳秒、左侧段号闪烁。
- **累计不丢失**：「已进行时间」是各段时长之和，暂停期间不走字，重启后继续累加。
- **开始时间不变**：始终是本次拍摄第一段的起始时刻，重启不会把它改掉。
- **控件自动隐藏**：闲置约 4 秒后顶部按钮淡出，不会出现在画面里。点一下屏幕任意处唤出控件，再点按钮才生效（避免误触）。
- **屏幕常亮**：调用 Wake Lock 防止自动锁屏（需 https 或 localhost）。
- **刷新不丢**：开始时间、各段记录会存到本地，误刷新页面也能恢复。

> 不到 1 秒的误触也会存成一条记录，用「清空记录」即可一次性除去。

## 配色与显示

点 **设置** 打开右侧面板：

- **7 套配色预设**：影院黑、纯黑、暖白纸、冷白纸、深海蓝、玫瑰、森林
- **自定义**：背景颜色、文字颜色、强调颜色（已进行时间）三个取色器，实时生效
- 整体字号（0.7×–1.6×）、文字标签开关、毫秒显示、12/24 小时制、分段记录条开关
- **复制分段记录**：导出成 `分段 / 开始 / 结束 / 时长` 的文本（开头附带拍摄开始时刻与有效时长），方便剪辑对时间
- **清空记录**：只清记录，不影响当前计时
- **复制配色链接**：生成带当前配色的网址，存成书签可一键拉起同一套配色

设置会自动记住，换配色不需要重新调。

## 快捷键（外接键盘 / 电脑预览）

`空格` 开始 / 暂停 / 重启 · `R` 重置 · `F` 全屏 · `S` 设置 · `Esc` 收起面板

## 在 iPad 上打开

### 方式一：本地文件（最快，但有功能限制）

把 `index.html` 传到 iPad 的「文件」App，点击用 Safari 打开。

> Safari 在 `file://` 下可能禁用 localStorage（配色设置无法记住）和 Wake Lock（屏幕常亮失效）。其他功能正常。

### 方式二：线上地址（推荐，功能完整）

直接用 **<https://jiuzhouu.github.io/PadView/>**，由 GitHub Pages 托管（仓库 Settings → Pages → Deploy from a branch → `main` / `/ (root)`）。

通过 https 打开时下面两项才能生效，这也是推荐用它而不是本地文件的原因：

| 功能 | `file://` 本地文件 | `https://` 线上地址 |
| --- | --- | --- |
| 配色设置能否记住（localStorage） | 可能被禁用 | ✅ |
| 屏幕常亮（Wake Lock） | ❌ | ✅ |
| 添加到主屏幕后全屏 | 一般 | ✅ |

改完代码推送即可自动更新：

```bash
git add -A && git commit -m "调整计时看板" && git push
```

进阶用法：可用 URL 参数直接指定配色，做成多个主屏幕图标：

```
https://jiuzhouu.github.io/PadView/?bg=000000&fg=ffffff&accent=22d3ee&ms=1
```

支持的参数：`bg` `fg` `accent`（十六进制，可省略 `#`）、`scale`、`ms`、`labels`、`h24`、`recordsVisible`、`autoHide`、`awake`（布尔用 `1`/`0`）。

### 添加到主屏幕获得全屏

Safari 打开后 → 分享 → **添加到主屏幕**。之后从图标启动没有浏览器地址栏，效果最接近原生应用。

### 别忘了关掉系统自动锁屏

Wake Lock 失败时的兜底：iPad「设置 → 显示与亮度 → 自动锁定 → 永不」。

## 拍摄前检查清单

1. 打开页面 → 点「设置」选好配色 → 收起面板
2. 用另一台手机拍一张测试画面，确认字看得清、颜色不串色
3. 点「开始」，然后别碰屏幕，等控件自动隐藏
4. 拍完一段就点「暂停」自动存记录，接着拍就点「重启」
5. 收工后点「设置 → 复制分段记录」，粘到备忘录里备查
